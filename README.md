# Projeto E-commerce (Frontend)
O objetivo deste desafio é criar uma aplicação que simule as funcionalidades de um e-commerce. A aplicação deve permitir a exibição de uma lista de produtos e possibilitar a interação com o carrinho de compras, como ajuste de quantidades e visualização dos itens selecionados. 

## Tecnologia 🚀
- React
- Tailwindcss
- Swipper 

## Funcionalidades obrigatórias:
- [X] Listagem de produtos com detalhes.
- [X] Carrinho de compras, incluindo ajuste de quantidades e exibição de itens selecionados.

## Funcionalidades extras next steps
 - [ ] Adicionar filtros (categorias, etc)
 - [ ] Barra de pesquisa funcional
 - [ ] Adicionar Paginação de produtos
 - [ ] implementar página de checkout
 - [ ] Adiconar página de login e cadastrar
 - [ ] Autenticação com JWT

## Rodando localmente

Clone o projeto

```bash
  git clone https://github.com/priscila-une/e-commerceReact.git
```

Entre no diretório do projeto

```bash
  cd pasta-do-projeto
```

Instale as dependências

```bash
  npm install
```

Inicie o servidor

```bash
  npm run dev
```
